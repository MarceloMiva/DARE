## About

DARE is a modular command-line toolkit for penetration testing and CTF challenges. It bundles the most common recon, enumeration, and exploitation assistance tools into a single interactive CLI — no switching between tools, no setup headache.

---

## Modules

| # | Module | Description |
|---|--------|-------------|
| 1 | **Recon & OSINT** | DNS enumeration, WHOIS, subdomain discovery |
| 2 | **Port & Service Scan** | TCP/UDP scanning with banner grabbing |
| 3 | **Web Enumeration** | Directory brute-force, CMS detection, HTTP analysis |
| 4 | **Hash Tools** | Hash ID, generation, and comparison (MD5, SHA-1, SHA-256+) |
| 5 | **Encoder / Decoder** | Base64, URL, Hex, ROT13, and more |
| 6 | **Exploit Helper** | Payload templates and CVE reference lookup |

## Quick Start

```bash
# Clone the repo
git clone https://github.com/MarceloMiva/DARE.git

# Navigate into the folder
cd DARE

# Install dependencies
pip install -r requirements.txt

# Launch DARE
python dare.py
```
